# Week1 Synthetic Python Output v1

## 任务与用途

给定完整 Python 源码，预测最后赋值 `result` 的最终整数值。标签共有 10 类：0–9。用于检查小 Transformer 的学习流程，以及为后续受预算约束的代码证据选择提供可控输入。

这是本项目自行生成的诊断数据，不是公开 benchmark，也不包含 LCC 数据。全部样例均随包提供。

## 数据量与划分

| 集合 | 256 字节 | 512 字节 | 1,024 字节 | 合计 | 每类依赖的模板数 |
|---|---:|---:|---:|---:|---:|
| train | 1,200 | 0 | 0 | 1,200 | 4 |
| validation | 120 | 120 | 120 | 360 | 2 |
| test | 180 | 180 | 180 | 540 | 2 |

每个集合、每种长度、每种依赖类型内部，答案 0–9 数量相等。每个长度的测试集都有 60 条赋值链、60 条函数调用、60 条条件返回样例。

本次 checkpoint 仅按 256 字节验证集交叉熵选择。512/1,024 字节验证数据已准备，但不参与本次调参或选 checkpoint。训练三个随机种子全部完成后才运行测试脚本。

## 字段

| 字段 | 含义 | 是否进入模型 |
|---|---|---|
| `code` | 可执行的受限 Python 源码 | 是，UTF-8 字节序列 |
| `target` | 固定为 `result`；查询由最终赋值语句体现 | 不单独编码 |
| `answer` | 正确整数值 | 仅用作训练标签/评估目标 |
| `gold_static_spans` | 按生成过程记录的保守静态证据字节区间 | 否 |
| `skeleton_id` | 模板结构编号 | 否 |
| `family_id` | 同一个生成实例的不同长度变体所属组 | 否 |
| `family` | chain/call/branch | 否 |
| `byte_length` | 不含 CLS 的源码字节长度 | 不单独编码 |
| `max_dependency_distance_bytes` | 从最早证据起点到源码末尾的粗略跨度 | 否；不是逐条 PDG 边距离 |

模型输入只从 `code` 构造。普通字节 token 为 0–255，PAD=256，CLS=257；总词表大小 258。256 字节样例实际进入模型的有效长度是 257，包括一个分类读出符。中文等非 ASCII 字符可能占多个字节，但这批生成数据只使用 ASCII。

## 受限语法

- 顶层单变量赋值、整数、加减运算。
- 函数使用一个位置参数，函数体为一条返回语句，或一条具有两个返回分支的 if/else。
- 函数可读全局整数变量；条件比较使用 `>` 或 `<=`。
- 变量不重绑定，没有递归、循环、类、容器、属性访问和外部库调用。
- 干扰语句使用与相关语句不冲突的变量名；只包含独立整数赋值。

赋值链模板改变三处运算符；函数模板改变加减与操作数顺序；分支模板改变比较符和两个分支中的运算符。模板 0–3 用于训练、4–5 用于验证、6–7 用于测试。

## 标签与正确性

先均衡安排目标标签，再反解源变量的整数值；中间值允许为负数，最终值保证在 0–9。受限 AST 解释器计算结果，另对全部 2,100 条生成样例使用 CPython 独立核对。

生成器在写出相关语句时记录证据区间。分析器仅从源码重新提取依赖；全量审查检查其证据块与生成标注相同。条件函数保留两个分支及条件来源，因此这是保守静态证据，不是执行时最小证据。

生成代码在运行时的标签核对仅适用于本地固定生成器产生的样例，不提供执行任意未知源码的接口。

## 去重与模板隔离

- 集合内部和集合之间没有完全相同的源码。
- 归一化相关语句 AST（去除干扰语句、变量名、字面常数、源码位置）后，训练/验证/测试之间没有重合。
- 同一 `family_id` 的多个长度变体始终在同一集合。
- 模板隔离是语法层面的。交换加法操作数或切换条件与分支仍可能产生语义等价程序，所以不能声称彻底消除一切语义近重复。

## 已知限制

1. 只有 24 个模板骨架，规模和语言覆盖很小；属于有限组合的泛化测试。
2. 因为训练模板与测试模板不同，未见模板与长度变化可能同时影响结果。256 字节测试隔离了长度因素；512/1,024 字节额外引入了长度因素。
3. 干扰代码主要是简单赋值，不能代表真实仓库中的复杂干扰与名称解析。
4. 部分分支模板的两个返回表达式相同，是退化条件样例；不能把整个 branch 子集当成每个样例都必须利用条件才能答对。
5. 标签均衡不保证没有捷径。数值范围、符号与模板仍可能提供统计线索；未来需要反事实配对与更复杂模板检查。
6. 长度由干扰赋值和少量空白填充得到；字节数不等于词法 token 数或 Qwen token 数。
7. 每个长度内的置信区间只描述当前小样本比例；跨长度数据具有配对关系，不能把 3 个长度或 3 个种子简单当成更多独立程序。

文件 SHA-256、样例数量和模板编号见 `data/manifest.json`；实际全量审查见 `results/data_audit.json`。
